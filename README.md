# Шар-Предсказамус 🔮

Мультяшный магический шар с 45 мемными ответами на русском. Задайте вопрос, потрясите шар и получите порцию космической мудрости — с мимикой, анимациями и копированием ответа.

## Локальный запуск

Скачайте все четыре файла в одну папку и откройте `index.html` двойным кликом. Установка, сборка и сервер не нужны; проект работает без подключения к интернету.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите `index.html`, `style.css`, `script.js`, `README.md` в корень ветки `main`.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку **main**, папку **/ (root)** и нажмите **Save**.
5. Дождитесь публикации. Ссылка появится в разделе Pages.

**Живой сайт:** [добавьте ссылку после публикации](https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/)

## Как изменить ответы

В `script.js` дополните массив `answers` объектами вида:

```js
{ text: "Это база. Да.", type: "yes" }
```

Доступные типы: `yes`, `no`, `maybe`. Тип определяет эмоцию персонажа. Выбор исключает повтор одинакового текста два раза подряд, в том числе после «Спросить ещё».

## Особенности

- Чистые HTML, CSS и JavaScript; SVG-персонаж находится прямо в разметке.
- Адаптивная вёрстка от 360 px, системные шрифты, без внешних ресурсов.
- Enter отправляет вопрос; пробелы не активируют кнопку; повторная отправка во время предсказания блокируется.
- Доступные подписи, видимый фокус, объявления ответа для скринридеров.
- Поддержка `prefers-reduced-motion`: анимации отключаются, ожидание сокращается.
- Копирование использует Clipboard API с резервным способом для локального файла. Если браузер запретит оба способа, появится уведомление.
