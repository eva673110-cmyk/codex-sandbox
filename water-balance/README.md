# Водный баланс

Открыть приложение: https://eva673110-cmyk.github.io/codex-sandbox/water-balance/

Личный дневник напитков. Регистрация по почте и паролю с подтверждением email. Каждый участник видит свой дневник; администратор видит статистику использования, без содержимого дневников.

Для разработки: npm start. Проверки: npm test. Сборка: npm run build.
